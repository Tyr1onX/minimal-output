# minimal-output

让 AI **充分理解，但只交付你真正要的结果**。

它主要解决四类常见问题：

- 用户纠正一个局部问题，AI 却顺手改了一大片；
- “不要出现 X”最后变成了文件名、标签或正文里的“禁止 X”；
- 最终结果夹杂大量纠错历史和防御性解释；
- 当前任务已经变化，AI 仍主动调用很早以前的旧上下文。

核心原则只有一句：

> **充分理解，最小修改，只呈现最终状态。**

## 示例

用户：

> 画一个苹果。

AI 错误地画了一棵苹果树。用户纠正：

> 不要树，我只要一个苹果。

启用本 Skill 后，目标会被重新归一化为：

> 一个苹果。

最终结果不应该出现“禁止树”“无树版”“修复树问题”等纠错痕迹。

## 适合使用

- 图片生成与修改
- README / 文档修改
- 代码局部修复
- GitHub 仓库维护
- 多轮对话中的连续迭代
- 任何容易出现过度解释或范围膨胀的任务

规则见 [`SKILL.md`](./SKILL.md)，回归样例见 [`tests/cases.md`](./tests/cases.md)。
